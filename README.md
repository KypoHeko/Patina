# 🌿 Patina

**Экспериментальный файловый менеджер**

`0.1` · Windows 10 · Rust + Tauri 2 · ванильный HTML/CSS/JS

</div>

---

## Зачем

Patina — это попытка собрать инструмент, построенный **вокруг индекса, а не вокруг списка файлов**: поиск, теги, граф связей, поиск дубликатов и история версий для любых файлов, не только кода.

---

## Возможности

### Навигация
- **Вкладки** в браузерном стиле с сохранением состояния и восстановлением закрытых (`Ctrl+Shift+T`).
- **Две панели** с независимой навигацией, хлебными крошками и перетаскиваемым разделителем.
- **Виртуализированный список** — плавная работа на каталогах в десятки тысяч файлов.
- **Нативные иконки** файлов (как в Проводнике), подгружаются лениво и кэшируются на диске.
- Колонки: имя, тип, теги, размер (включая вычисляемый размер папок), дата изменения.

### Поиск — палитра команд (`Ctrl+K`)
- Три области поиска: **текущая папка**, **всё поддерево**, **по содержимому файлов**.
- Режим **регулярных выражений**.
- Фильтр по тегам (пересечение, AND).

### Организация
- **Теги** с цветовой кодировкой: Срочно, В работе, Готово, Справка, Архив.
- **Облако тегов** в сайдбаре со счётчиками.
- **Быстрый доступ** (Домашняя, Рабочий стол, Документы, Загрузки) — редактируемый.
- **Индикаторы хранилищ**: метки томов, тип носителя (SSD/HDD), занято/всего.

### Умные инструменты
- **Граф связей** (`Ctrl+G`) — интерактивный canvas-граф зависимостей и обратных ссылок между файлами.
- **Поиск дубликатов** (`Ctrl+D`) — группировка по хешу содержимого (BLAKE3), действия Keep/Delete.
- **История версий** — снимки любого файла с таймлайном, восстановлением и удалением; перед восстановлением автоматически снимается предохранительная копия текущего состояния.
- **Предпросмотр** — миниатюры изображений и текст, плюс панель информации о файле.

### Файловые операции
- Копирование, перемещение, переименование, создание папок.
- Удаление **в Корзину** (нативный `IFileOperation` на Windows — поддержка UAC, длинных и UNC-путей).
- Обнаружение конфликтов имён с диалогом подтверждения.
- Открытие в приложении по умолчанию и «Показать в Проводнике».

### Живой индекс
- Инкрементальная синхронизация через **NTFS USN Journal** — без постоянного пересканирования диска.
- Слежение за изменениями в реальном времени (`notify`).
- Фоновая агрегация размеров папок.

## Горячие клавиши

| Комбинация | Действие |
|---|---|
| `Ctrl+K` | Поиск / палитра команд |
| `Ctrl+D` | Поиск дубликатов |
| `Ctrl+G` | Граф связей |
| `Ctrl+T` | Новая вкладка |
| `Ctrl+W` | Закрыть вкладку |
| `Ctrl+Shift+T` | Открыть закрытую вкладку |
| `Ctrl+Shift+N` | Создать папку |

## Технологии

| Слой | Стек |
|---|---|
| Бэкенд | Rust, Tauri 2 |
| Индекс | SQLite (rusqlite, WAL), 13 миграций |
| Хеширование | BLAKE3 |
| Версии | контент-адресуемое хранилище: full / zstd со словарём / chunked-дедупликация |
| Платформа | WinAPI (`windows`): нативные иконки, Корзина, тома, USN Journal |
| Фронтенд | ванильный HTML/CSS/JS, нативные ES-модули (без сборщика) |
| Тесты | Vitest (фронтенд) + `cargo test` (бэкенд) |

Архитектура: фронтенд общается с бэкендом **только** через тонкий слой обёрток `invoke` (`src/js/api/`). Состояние — единый observable-стор плюс шина событий. Бэкенд разложен по слоям: команды (IPC) → сервисы (fs/index/indexer) → репозитории → модели; платформенный код изолирован под `cfg`-флагами.

Безопасность: строгий CSP, `freezePrototype`, отключённый нативный drag-drop, минимальные capabilities, экранирование всех данных при вставке в DOM.

## Сборка и запуск

**Требуется:** Rust ≥ 1.85 (edition 2024), Node.js (только для тестов фронтенда), [системные зависимости Tauri](https://tauri.app/start/prerequisites/).

```bash
# Запуск в режиме разработки
cargo tauri dev

# Релизная сборка (установщик)
cargo tauri build

# Тесты фронтенда
npm install
npm test

# Тесты бэкенда
cd src-tauri && cargo test
```

## Структура проекта

```
patina/
├── src/                 # фронтенд (ваниль)
│   ├── index.html
│   ├── js/
│   │   ├── api/         # единственная граница с Tauri (обёртки invoke)
│   │   ├── core/        # стор, шина событий, базовый Component, шорткаты
│   │   ├── components/  # UI-компоненты
│   │   ├── state/       # срезы состояния
│   │   ├── lib/         # помощники (формат, виртуализация, regex, иконки)
│   │   └── test/        # тесты Vitest
│   └── styles/          # токены темы + CSS по компонентам
└── src-tauri/           # бэкенд (Rust)
    └── src/
        ├── commands/    # тонкий слой IPC-команд
        ├── fs/          # файловые операции
        ├── index/       # SQLite-индекс, репозитории, миграции
        ├── indexer/     # фоновые воркеры (скан, USN, хеши, ссылки)
        ├── platform/    # ОС-специфика (WinAPI)
        └── models/      # доменные структуры
```

## Статус

**0.1 — ранняя версия.** Приоритетная платформа — Windows 10. Кроссплатформенный код частично заложен, но не цель этого релиза.

### Известные ограничения
- Тип хранилища «Cloud» пока не определяется (отображается как «Диск»).
- Поиск дубликатов и контентный индекс работают по поддереву активного корня.
- Восстановление версии перезаписывает живой файл (текущее состояние при этом сохраняется в историю).
